# 🏦 Carpeta de Logos de Bancos - CambiosAI

Guardá aquí las imágenes de los logos de cada banco. El sistema las detectará y mostrará automáticamente en todo el sistema (Dashboard, Historial de Operaciones, Ajuste de Caja y Arqueo).

### 💡 Consejos para la mejor calidad visual:
1. **Formato:** PNG con fondo transparente (o fondo del color corporativo) o SVG.
2. **Proporción:** Cuadrado (por ejemplo `200x200` o `512x512` px).
3. **Automático:** Si un logo no se encuentra en esta carpeta, el sistema muestra automáticamente el isotipo vectorizado oficial sin romperse.
